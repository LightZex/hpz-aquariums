# HPZ Aquaroom

Showroom cá cảnh trực thuộc hệ thống **HPzoo Ecosystem** — Cầu Giấy, Hà Nội.

Web giới thiệu showroom với hơn 100 loài cá cảnh: betta, koi, cá rồng, cá bảy màu... kèm tìm kiếm theo tên, đánh giá khách hàng và liên hệ trực tiếp qua Facebook.

## Tính năng

- Trang chủ 1 trang: Hero, Giới thiệu, Bể cá nổi bật, Đánh giá, Liên hệ
- Trang **Bể cá**: danh mục 100+ loài cá, tìm kiếm tiếng Việt/tiếng Anh
- Nền đại dương động: god rays, đàn cá bơi, bong bóng, dải cát đáy biển với san hô - sao biển - sò ngọc trai
- Review carousel chạy liên tục
- Responsive mobile/desktop

## Công nghệ

HTML + CSS + JavaScript thuần (không framework), canvas 2D cho hiệu ứng biển.
